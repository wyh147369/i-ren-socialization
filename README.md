# i-ren-socialization

面向内向者（i人）的中文社交技能库。由《i人社会化攻略 2.0》PDF 经 book-to-skill 转化而来，覆盖 33 课社交场景（心态 / 表达 / 关系 / 场面 / 职场）。

## 包含内容
- `SKILL.md` —— 场景路由表、六条核心原则、33 章导览
- `chapters/ch01–ch33.md` —— 33 课完整内容（14 课含可照抄的 Worked Example）
- `patterns.md` —— 21 个可复用社交公式（敬酒四公式、拒绝五档、会议发言结构…）
- `cheatsheet.md` —— 一页速查，全是能直接照抄的原话
- `glossary.md` —— 60+ 术语（装E、献可替否、捧杀、灯塔策略、社交能量条…）

## 安装（WorkBuddy）
把本仓库放到用户级技能目录并重启/刷新 WorkBuddy：
- Windows：`C:/Users/<你>/.workbuddy/skills/i-ren-socialization/`
- macOS/Linux：`~/.workbuddy/skills/i-ren-socialization/`

之后直接在对话里说场景即可调用，例如：
「明天要敬领导酒怎么说」「同事让我干分外的事怎么拒」「被当众怼了怎么回击」
