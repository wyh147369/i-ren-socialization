# 第7课 人见人爱的嘴甜话术

## Core Idea
嘴甜公式：`笑脸迎人 + 夸人环节 + 融入肢体表情 + 眼神真诚`。夸人的分水岭在于**夸完要做具体描述**，以及**优先夸后天努力而非先天长相**。

## Frameworks Introduced

- **嘴甜公式**：`笑脸迎人 + 夸人环节 + 融入肢体表情 + 眼神真诚`
  - **笑脸迎人**：不管熟人还是半生不熟，都不躲避目光。附带效应——微笑会暗示大脑你很开心，然后你真的会变开心。
  - **夸人环节**：见下方"夸人的两条升级路径"
  - **融入肢体表情**：适当夸张的手势和表情 + 语调上扬。**不要担心显得浮夸**——对方心里乐开花了。
  - **眼神真诚**：不看着对方夸 = 敷衍。反例正是服装店试衣时朋友看都不看就说好看。

- **夸人的两条升级路径**
  1. **夸完 + 具体描述**：从"哇你好漂亮"升级为"哇你好漂亮呀，眼睛好大，就像个洋娃娃一样"。空泛形容词的问题不是不中听，是**别人不好接**。
  2. **优先夸后天努力**：赞美穿搭、发质、皮肤、妆容、品味 > 赞美长相。如果还表示"被安利到了"，对方不仅收到情绪价值，还会觉得你是同类。
     - "哇你的卷发好好看，你是自己卷的嘛，你也太厉害了吧，教我！"
     - "你皮肤好好呀，一点瑕疵都没有，好想知道你用的是什么护肤品呀"
     - "你的发色好好看，好适合你呀，看你染的这么好看我都想染了！"

- **被夸时的正确反应**：大方接住 + 引出话题。"真的嘛，谢谢你，好开心呀"，然后顺着夸的点延伸（对方夸你发质好 → 安利洗发水和护理方法）。**话题就这么出来了。**

## Key Concepts
- **尬夸**：只堆砌形容词不描述，显得空洞且让对方无法接话
- **后天努力 vs 先天长相**：前者的夸奖更有效，因为对方在其中投入了成本
- **被安利到**：最强的夸奖升级动作，同时给出情绪价值和同类认同
- **肢体可信度**：手势、表情、语调上扬共同构成夸奖的可信度

## Mental Models
- **Use "夸完必须跟一句具体描述"当默认动作。** 形容词堆砌是 i 人最常见的省事做法，也是效果最差的做法。
- **Use 后天努力当夸奖对象。** 夸长相是给天赋打分，夸穿搭/妆容/品味是给选择打分——后者才让人觉得被看见。
- **Think of 微笑 as 双向的。** 对外是第一印象，对内是情绪暗示。
- **Use 被夸的场合当话题发生器。** 接住夸奖后顺着内容延伸，一次夸奖能换来三段对话。

## Anti-patterns
- **尬夸**："哇你好漂亮""你好可爱"然后没了——空洞，且对方不好接。
- **不看人就夸**：眼神不接触的夸奖等于敷衍。
- **怕显得浮夸而收着手势**：作者立场相反——对方只会更开心。
- **被夸时过度谦虚否认**：会把话题堵死，正确做法是接住并延伸。

## Key Takeaways
1. 嘴甜四件套：笑脸、夸人、肢体表情、眼神真诚。
2. 夸完必须加具体描述，否则空洞且难接话。
3. 优先夸后天努力（穿搭/发质/皮肤/妆容/品味），比夸长相有效得多。
4. 加上"我也被安利到了"，对方会觉得你是同类。
5. 别怕手势浮夸，配合语调上扬才可信。
6. 被夸时大方接住并顺势延伸出话题。
