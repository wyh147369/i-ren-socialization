# 第17课 饭局接待礼仪

## Core Idea
饭局全流程：点菜 → 接待 → 用餐 → 送别。核心判断是**把专业的事交给专业的人**（点菜找点菜师），以及**维护所有人的体面**。

## Frameworks Introduced

- **点菜（领导让你点）**
  - 做法：加酒楼营运经理微信，让酒楼**点菜师**过来，提供预算和要求，拿两三套组合，不适合的换掉。理由很实在：**经常商务宴请的酒楼比我们专业多了**（不同地区份量不同，交流中还能得到经验分享）。
  - 禁忌：**不要点容易吃成小花脸小脏手的菜**——鹅掌、刺很多的鱼、皮很韧的鸡。目的是维护成年人的体面。

- **接待流程**：①准时迎接，一般提前到餐厅门口热情等待 ②引领入座，帮宾客熟悉周边环境

- **用餐过程**：①适时介绍特色菜品、带动餐桌话题，但不打扰用餐 ②关注细节，及时添茶，留意宾客需求

- **倒酒礼仪**（服务员不在场时由秘书/助理上场）
  - **顺序**：从主宾开始顺时针，"先宾后主，先尊后卑"
  - **斟酒量**：白酒约八分满（表尊重又避免溢出）；啤酒视杯子大小适量，不宜过满
  - **操作**：动作稳重缓慢，瓶口不触杯口，尽量安静，避免不雅声响

- **敬酒礼仪**
  - 首次敬酒由**主人发起**，随后按职位高低轮流
  - 姿态：起身站立，右手持杯，左手托杯底（杯体较热可轻握杯身），**杯口略低于对方杯口**
  - 言辞：简短得体的祝词（对合作的祝愿、对对方成就的认可），诚恳恰当
  - **不强劝酒**；对方不能饮酒可用饮料代替并同样尊重
  - 回应敬酒：起身举杯相碰、眼神交流、微笑致谢

- **结束送别**：①主动提出送宾客返回 ②次日再次联系，感谢出席并跟进洽谈内容

## Key Concepts
- **点菜师**：酒楼的专业角色，比自己点更可靠
- **先宾后主，先尊后卑**：倒酒顺序原则
- **八分满**：白酒斟酒量，兼顾尊重与不溢出
- **杯口略低**：敬酒时的敬意表达
- **不强劝酒**：明确提倡健康饮酒

## Mental Models
- **Use 点菜师当你被要求点菜时。** 这是全书少见的"承认不专业并外包"的建议，效果最好。
- **Use "会不会吃相难看"当筛选菜品时。** 饭局的第一目标是体面，不是好吃。
- **Use 杯口略低当无声的敬意。** 姿态比祝词先被看到。
- **Use 次日跟进当关系落点。** 饭局本身不产生关系，次日的联系才产生。

## Anti-patterns
- **自己硬扛点菜**：酒楼更专业，且能给出份量经验。
- **点难啃的菜**：鹅掌、多刺鱼、韧皮鸡——破坏体面。
- **强劝酒**：明确禁止，尊重对方选择。
- **瓶口碰杯口、倒酒出声**：操作不雅。
- **饭局后不跟进**：少了一次把场面转成关系的机会。

## Key Takeaways
1. 领导让你点菜 → 找酒楼点菜师，给预算拿两三套组合。
2. 不点吃相难看的菜，维护体面。
3. 提前到门口迎接，引领入座。
4. 倒酒：主宾起顺时针，先宾后主先尊后卑；白酒八分满；瓶口不碰杯口。
5. 敬酒：主人先发起，起身、右手持杯左手托底、杯口略低于对方。
6. 不强劝酒，不能饮者以饮料代。
7. 结束后主动送客，次日再联系致谢并跟进。
