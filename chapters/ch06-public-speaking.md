# 第6课 公开场合发言的表达力训练

## Core Idea
私下能侃侃而谈、上台就大脑空白——问题不在胆量，在**输入不足 + 输出不足**。作者本人的解法是一个字练出来的：`输入 + 输出` 双循环。

## Frameworks Introduced

- **输入四件套**：① 多看书（表达工具书 + 感兴趣的书，积累观点和知识，发言才有深度）② 看表达类综艺（奇葩说、脱口秀，学怎么把观点说得生动）③ 看辩论赛（网上大量"神级辩论现场"）④ **减少短视频**——碎片化信息降低专注力，且充斥重复的网络用语，看久了词汇量骤降

- **输出四件套**：① 每天大声朗读 20 分钟（找新闻稿或演讲稿，在没人的地方读——结巴往往只是因为开口太少）② 转述法（看完稿子用自己的话复述并评价，要求有理有据、条理清楚，录音计时，从讲满一分钟开始逐步加长）③ 主动争取上台机会（小组作业里没人愿意汇报的那次，你去）④ 多表达看法（刷小红书时评价笔记：好在哪、哪些观点有启发、哪些地方需要优化，还能和评论区交流）

## Key Concepts
- **输入 → 输出**：表达力是双向循环，只输入不开口无效，只开口没内容也无深度
- **转述法**：最低成本的输出训练，可量化（录音 + 计时 + 逐步加时长）
- **词汇量骤降**：短视频对表达力的具体损伤机制
- **深度阅读能力**：可先用听书过渡，再回到读

## Mental Models
- **Think of 大脑空白 as 提取失败，not 没准备。** 朗读和转述练的是提取速度。
- **Use "没人会记得你的丑，但进步是实打实的"当行动许可。** 作者自己上台唱过歌、主持过整场晚会，也出过很多糗。
- **Use 计时当量化指标。** "讲满一分钟"比"多练练"可执行得多。
- **Use 日常场景当训练场。** 刷小红书写评论也是输出练习——训练不必找专门时间。

## Anti-patterns
- **只准备不练习**：提前准备很久仍会卡壳，因为缺的是输出训练不是稿件。
- **把短视频当输入**：明确点名的负向行为，损伤专注力和词汇量。
- **不敢争取上台**：把汇报机会让出去，就永远没有真实压力下的训练。

## Key Takeaways
1. 表达力 = 输入（书/综艺/辩论）+ 输出（朗读/转述/上台/表态）双循环。
2. 少看短视频，它直接损伤词汇量和专注力。
3. 每天大声朗读 20 分钟，解决"开口太少导致的结巴"。
4. 转述法要录音计时，从一分钟起逐步加长。
5. 主动抢没人愿意做的小组汇报——那是免费的高压训练场。
6. 出丑没人记得，进步是实打实的。
