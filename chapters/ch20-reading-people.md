# 第20课 识人术防止踩坑

## Core Idea
14 条识人判据。三条最实用的：**看不穿的人就看他身边亲近的人**、**日久见人心**、**答应太爽快的人往往靠不住**。

## Frameworks Introduced

- **绕过伪装法**：`看不穿他 → 看他身边亲近的人`
  - When to use: 对方善于伪装、你无法看出真实面目时
  - 原理：人以类聚，看他身边人的样子，判断他能八九不离十。

- **行为优于语言**：`看肢体语言、微表情、以及他具体做了什么`
  - 一次见面、一件事情看不出真实面目；时间长了，再善于伪装也会露马脚——**日久见人心**。

- **沉默几秒再答 = 靠谱**：
  - 突然提出请求时，能沉默几秒再回答的人是在思考可行性，做人做事认真。
  - **答应得特别爽快的人，往往靠不住。**

- **情绪稳定 = 危险**：
  - 被挑衅攻击仍情绪稳定、轻易不动怒的人，自控力极强、**反击手段也特别狠**，千万别小看。
  - 反面：动不动生气、爱发脾气的人没什么城府心机，内心想法容易被看穿和被利用。

- **利益/危难测试**：`称兄道弟的不一定是朋友`
  - 在利益冲突面前或遇到危难时还能为你着想的人，才值得深交。

## Key Concepts
- **城府**：内心想法不外露的能力；话少者多半是稳重有城府，而非孤僻
- **日久见人心**：时间是最可靠的识人工具
- **微表情 / 肢体语言**：比话语更可信的信号源（呼应 ch03 的"看行为 > 听话"）
- **忠言逆耳**：真正在乎你的人说话不会花言巧语，甚至让你不舒服
- **熟得太快**：对谁都如此，且忘得也快

## 判据速查
| 观察 | 判断 |
|---|---|
| 被挑衅仍不动怒 | 自控力极强，反击手段狠，别小看 |
| 动不动发脾气 | 无城府，易被看穿和利用 |
| 善于伪装看不透 | 看他身边亲近的人 |
| 话少 | 多半是稳重有城府，不是孤僻 |
| 信口开河、满嘴跑火车 | 不能深交，不能委以重任 |
| 和你熟得太快 | 对任何人都如此，忘得也快 |
| 说话不花言巧语甚至让你不舒服 | 真正在乎你（忠言逆耳） |
| 倾诉/表现欲强、爱发朋友圈 | 大多内心单纯 |
| 突然请求时沉默几秒再答 | 认真靠谱 |
| 答应特别爽快 | 往往靠不住 |
| 关门小声、手机不外放 | 心思细腻，为他人着想 |
| 说话慢但有条理 | 有原则和底线，人生有规划 |

## Mental Models
- **Use 他身边的人当镜子。** 看不透本人时，这是唯一可靠的旁证。
- **Use 时间当筛子。** 不要凭一次见面下结论——这是识人最常见的错误。
- **Use "他答应有没有经过思考"当可靠度指标。** 秒答应 = 没评估 = 大概率做不到。
- **Use 利益和危难当试金石。** 顺境里的称兄道弟不构成证据。
- **Use 让你不舒服的真话当正面信号。** 花言巧语成本低，逆耳忠言成本高。

## Anti-patterns
- **凭一次见面、一件事情判断一个人**：明确点名为不可能。
- **只听他说了什么**：必须配合肢体语言、微表情和实际行为。
- **把"熟得快"当成"在意你"**：恰恰相反。
- **小看不动怒的人**：这类人反击最狠。
- **深交信口开河的人**：不能委以重任。

## Worked Example
你托一个同事办一件需要协调资源的事，他秒回"没问题，包在我身上"。

按本课判据：**"答应特别爽快的人，往往靠不住"**——他没有沉默思考可行性，说明没有真正评估过协调成本。

对照做法：不要因为这个承诺而停止准备 Plan B；把"包在我身上"当作意向而非承诺，隔几天主动确认进展。若对方确实在推进，再逐步交托。

反过来，若对方沉默几秒才回答"我得先问问 X 部门的排期，明天给你准信"——这才是靠谱的信号。

## Key Takeaways
1. 看不透本人就看他身边亲近的人。
2. 日久见人心，别凭一次见面下结论。
3. 看肢体语言、微表情和实际行为，不只听话。
4. 不动怒的人自控极强、反击很狠，别小看；爱发脾气的人没城府。
5. 话少多半是稳重有城府。
6. 熟得太快 = 对谁都这样，忘得也快。
7. 沉默几秒再答的人靠谱；秒答应的人靠不住。
8. 利益冲突或危难时仍为你着想的人，才值得深交。
