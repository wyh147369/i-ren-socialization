# 第18课 敬酒万能话术

## Core Idea
作者立场先摆明：**不赞同酒桌文化，但这是进入社会不可避免的事**。i 人面对饭局尤其局促，所以给四套可直接套用的敬酒公式 + 五条注意事项。

## Frameworks Introduced

- **① 敬领导**：`感谢 + 具体事例 + 祝愿`
  - "李总我敬您，感谢领导这些年对我的栽培和认可，特别是 xxx 事上，给予了我极大的帮助，我至今难忘，这杯我敬您，再次感谢您的鼓励，接下来我一定努力工作，不负您的期待，也祝您好运常伴，长安常乐"

- **② 领导让你敬大家**：`感恩 + 抬大家 + 自我介绍 + 祝福`
  - "感谢领导给我这个机会，带着我来这个饭局，让我有幸与这么多业内的前辈们一起吃饭，光听大家聊天都能学好多东西呢。我叫小 x，在公司是负责 xx 板块，这杯酒敬大家，祝各位劲松不歇脚，青山正当年，顺顺我，事事如意，我先干了！"
  - Ps：**善用对句和叠词**会让人觉得你有底蕴

- **③ 敬初次见面的陌生领导**：`自我介绍 + 转述 + 表态`
  - "李总您好，我是小 x，经常听领导说起您过去的事迹，非常崇拜您，今天终于有幸能有机会敬您一杯酒，祝您万事顺意，如果有以后用得着我的地方，您随时召唤一声就好！"

- **④ 敬同事**：`感谢 + 具体事例 + 祝愿`
  - "跟您一起共事，很开心，特别是上次我休假期间，您帮我承担了所有工作，我特别感激，这杯酒我敬您，祝您事业蒸蒸日上，家庭幸福安康。"

- **注意事项**
  - 切不可打断领导和其他人的谈话
  - 给领导敬酒要**站起来、双手举杯、杯子要低、自己先干为敬**
  - 敬酒词**简明扼要**，不要长篇大论——没人愿意听你在酒桌上做"报告"
  - 对领导说敬酒词要看你们平时的关系、你在公司的位置及待遇；**太过客套与迂腐都不好**，按自己的实际情况说最好

## Key Concepts
- **具体事例**：所有敬酒公式的公共项，是诚意与空话的分界线
- **对句和叠词**：提升底蕴感的修辞（"劲松不歇脚，青山正当年"）
- **转述**：敬陌生领导时的信任桥梁（"经常听领导说起您"）
- **先干为敬**：给领导敬酒的姿态要求

## Mental Models
- **Use "感谢 + 具体事例 + 祝愿"当不知道说什么时。** 这是万能底座，四类对象都可套。
- **Use 具体事例当诚意来源。** 没有事例的敬酒词就是套话，听的人分得出来。
- **Use 对句叠词当你需要显得有底蕴时。** 低成本的文采提升。
- **Use "不要太长"当控制篇幅时。** 酒桌不是报告厅。

## Anti-patterns
- **打断别人谈话去敬酒**：时机错误。
- **坐着敬领导、杯子比对方高**：姿态失礼。
- **长篇大论**：没人愿意在酒桌上听"报告"。
- **过于客套迂腐**：不看关系和自身位置，照搬华丽模板反而不自然。

## Key Takeaways
1. 敬领导 = 感谢 + 具体事例 + 祝愿。
2. 领导让你敬大家 = 感恩 + 抬大家 + 自我介绍 + 祝福。
3. 敬陌生领导 = 自我介绍 + 转述 + 表态。
4. 敬同事 = 感谢 + 具体事例 + 祝愿。
5. 具体事例是所有公式的诚意所在，不能省。
6. 站起来、双手举杯、杯口要低、先干为敬。
7. 简明扼要，不打断别人，别太迂腐。
