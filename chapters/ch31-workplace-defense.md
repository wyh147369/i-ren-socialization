# 第31课 职场心眼子训练

## Core Idea
结尾一句是全部立场的总结：**职场需要"心眼子"，不是为了算计别人，而是为了不被轻易算计。保持真诚但带点锋芒，专注提升自身能力，才是长久之道。** 五大类：自我保护、沟通技巧、人际关系、工作习惯、心态调整。

## Frameworks Introduced

- **一、自我保护类**
  - **防甩锅**："这个任务之前我们分工是 XXX，目前我这部分已经完成，可能需要你再确认一下你的部分。" / "好的，我先把我的工作内容和时间线整理一份文档发群里，大家同步一下进度。" → **核心：留痕（邮件、聊天记录）、明确分工**
  - **防套话**：转移话题"哈哈，我最近光顾着忙项目了，都没注意这些事"；模糊回答"领导安排什么我就做什么，其他没多想" → **核心：不评价他人、不透露隐私**
  - **拒绝白嫖**："我现在手头有 XX 任务在赶进度，等忙完这阵再帮你看看？" / "这个我不太熟悉，建议你找 XX 部门的小李，他更专业。" → **核心：学会说不，先完成分内工作再量力而行**

- **二、沟通技巧类**
  - **避免直球**："这个思路挺有意思的，不过如果从 XX 角度考虑，会不会更稳妥？" / "我之前遇到过类似情况，当时试了 XX 方法效果不错，要不要参考一下？" → 先肯定再委婉提建议
  - **应对阴阳怪气**：装傻"哈哈，最近项目确实有点挑战，不过挺有收获的"；反夸对方"你效率这么高，教教我呗！" → **核心：不接负面情绪**
  - **领导画饼**：表达感谢"谢谢领导信任，我会继续努力！" + **追问细节**"您提到的机会大概在什么时间？我需要提前准备什么？" → **核心：保持积极但不轻信口头承诺，争取落到纸面**

- **三、人际关系类**
  - **小心小团体**：保持中立"我刚来还不了解情况，先做好手头工作吧"；装忙离开"哎呀，客户找我改方案，回头聊！"
  - **识别捧杀**：谦虚回应"都是团队合作的结果，大家功劳一样大"；**明确底线**"我手头任务已经排到下周了，这个新任务可能需要领导协调资源" → 核心：不贪图虚名，量力而行
  - **应对抢功劳**：**预防**——定期向领导同步进展（邮件/周报），关键节点拉群沟通；**反击**——"这个数据是我上周和 XX 部门对接后拿到的，中间确实费了不少功夫。"

- **四、工作习惯类**
  - **防背刺**（同事私下要你的方案/数据"参考"）：模糊回应"我还没整理完，等领导确认后再发你吧"；公开分享"我直接发群里吧，大家一起提提意见" → **核心：避免私下给关键资料**
  - **远离低级错误**（同事让你代提交文件/传话）：拒绝代签"公司规定文件必须本人签字，我帮你联系行政吧"；避免传话"这事我转达不清楚，建议你直接找 XX 沟通" → **核心：不替他人做决策**
  - **警惕越级汇报**：当场"好的，我先和 XX 经理同步一下这个任务，避免工作冲突"；事后向直属领导报备"刚才 X 总安排了一个任务，您看是否需要调整优先级？" → **核心：尊重直属上级**

- **五、心态调整**
  - **不追求被所有人喜欢**："职场是来赚钱的，不是来交朋友的。"
  - **接受合理冲突**：只要对事不对人，争论方案很正常
  - **保持钝感力**：对同事的负面评价或冷落，选择性忽略

## Key Concepts
- **留痕**：邮件、聊天记录、群内同步——职场自保的第一手段
- **捧杀**：用当众夸奖把你架到超负荷位置
- **钝感力**：对负面评价选择性忽略的能力
- **落到纸面**：口头承诺的唯一解药是追问具体时间
- **越级汇报**：看似是机会，实则是风险
- **锋芒**：真诚但带点锋芒，是本课给 i 人的目标态

## Mental Models
- **Use 留痕当默认动作。** 分工、进度、成果都留可见记录——争议时唯一有效的是记录。
- **Use "先肯定再转弯"当否定上级方案时。** 直球会得罪人，效果反而更差。
- **Use 追问细节当应对画饼的工具。** 不当场质疑，只问"什么时候、我要准备什么"——承诺会自己现形。
- **Use 公开化当防背刺的手段。** 私下给资料 = 给对方篡改和冒用的空间；发群里 = 留痕且公开。
- **Use "职场是来赚钱的"当心态锚点。** 不被喜欢不是失败指标。
- **Use 同步 + 报备当越级任务的标准流程。** 接任务前同步直属，接完后报备。

## Anti-patterns
- **不留痕**：背锅时无凭无据。
- **对同事评价领导、透露隐私**：职场边界感的基本禁忌。
- **来者不拒地帮忙**：分内工作被拖垮，且形成预期。
- **直接否定方案**：用"思路挺有意思 + 换个角度"替代。
- **接住对方的负面情绪**：阴阳怪气要用装傻或反夸化解，不接招。
- **相信口头承诺**：不追问时间就永远不会有时间。
- **参与站队、议论是非**：小团体的风险远大于收益。
- **贪图当众表扬**：捧杀之后是超负荷和摔死。
- **私下发关键资料**：防止被篡改或冒用，改发群里公开分享。
- **替人代签、替人传话**：直接成为背锅侠。
- **越级接任务不报备**：会被直属领导视为越权。

## Worked Example
大领导跳过你的直属经理，直接给你布置了一个任务。

- ❌ 直接接下 → 直属经理认为你越权，且后续资源协调会卡住
- ✅ **两步走**：
  1. 当场："好的，我先和 XX 经理同步一下这个任务，避免工作冲突。"（不拒绝大领导，同时保留流程）
  2. 事后向直属经理报备："刚才 X 总安排了一个任务，您看是否需要调整优先级？"（把优先级决定权交回直属领导）

一个动作同时满足了三方：大领导觉得你配合、直属领导觉得你尊重他、你避免了日后的位置尴尬。

## Key Takeaways
1. 心眼子是为了不被算计，不是为了算计别人；真诚但带点锋芒。
2. 防甩锅：留痕 + 明确分工，进度发群同步。
3. 防套话：转移话题或模糊回答，不评价他人不透露隐私。
4. 拒绝白嫖：先说手头任务，或推荐更专业的人。
5. 否定方案用"思路挺有意思 + 换个角度会不会更稳妥"。
6. 阴阳怪气用装傻或反夸，不接负面情绪。
7. 领导画饼：感谢 + 追问具体时间和准备事项，争取落纸。
8. 防抢功劳：定期同步进展、关键节点拉群；被抢时当众说出你的具体贡献。
9. 防背刺：不发私下资料，改发群里。
10. 不代签不传话；越级任务先同步直属、事后报备。
11. 职场是来赚钱的不是来交朋友的；保持钝感力。
