# 第5课 教你如何延伸话题

## Core Idea
对方说了件小事、你不知道怎么接、双方尬住——这是 i 人最高频的死局。四种方法把任何一句话接下去：**5W1H、发表看法感受、相关记忆、上深下切平移**。

## Frameworks Introduced

- **方法一｜5W1H 提问法**：从对方那句话里拆出六个可问的维度
  - What（什么）/ When（什么时候）/ Why（为什么）/ Where（哪里）/ Who（谁）/ How（怎么样）
  - When to use: 对方抛出一个陈述句，你完全不知道接什么时——这是最先该试的兜底工具

- **方法二｜发表你的看法和感受**：给态度，不给提问
  - 三种可选立场：赞同 / 反对 / 其他看法
  - When to use: 连问六个问题会像审讯时，改用表态来推进对话

- **方法三｜相关记忆法**：从对方话里**抓关键词**，去记忆库里调取相关经历
  - How: 抽出关键词 → 搜索过往记忆 → 讲出那段具体经历（越具体越有画面感，如"我想做土豆烧排骨，结果把排骨都烧黑了"）

- **方法四｜上深下切平移法**：对话题做三种方向变换
  - **上深**：上升到更有探讨价值的维度（由"想吃火锅"推断对方口味偏重、推断家乡）
  - **下切**：下沉到更细的子话题（喜欢什么口味火锅、一般下哪些菜、有想去的店吗、上次吃是什么时候、吃过哪些类型）
  - **平移**：把陌生领域的话题，关联到同等意义下你更熟悉的领域（重庆火锅好吃 → 想去重庆玩 → 你去过吗、感受怎么样）
  - When to use: 话题快聊死时。**平移尤其重要**——它让你把不熟的话题拽回自己的主场。

## Key Concepts
- **关键词**：相关记忆法的触发点，一句话里挑 1-2 个名词就够
- **上深 / 下切 / 平移**：话题的三个移动方向，分别对应"拔高、细化、横向转移"
- **尬住**：对话中断的状态，本质是双方都没有生成下一个话题的动作
- **延伸话题**：不换话题而在原话题上加深（见 ch04）

## Mental Models
- **Think of 任何一句陈述 as 六个潜在问题的集合。** 不知道接什么时，5W1H 扫一遍，总能挑出一个能问的。
- **Use 平移当话题超出你的知识范围。** 不用假装懂，横向挪到你熟悉的等价领域即可。
- **Use 具体细节当记忆法的燃料。** "我也做过饭"是废话，"我把排骨烧黑了"才是能接话的内容。
- **Use 表态当提问已过量时。** 连续追问会变成审讯，表态能把对话从问答模式切回聊天模式。

## Anti-patterns
- **连续追问不表态**：六个 W 全问一遍就成了查户口。
- **只给抽象回应**："挺好的""哈哈"不携带任何可接的信息，等于把球扔回对方。
- **聊死就立刻换话题**：先用上深/下切/平移救，救不回来再换（见 ch04：延伸是从不熟走向熟悉的基础）。

## Worked Example
对方说："今天不点外卖了，我自己从家里做了饭带过来吃。"

**方法一 · 5W1H**
- What：什么样的饭（你做了哪些菜呀？）
- When：什么时候做的（昨天晚上就做好了吗，还是今早现做的？）
- Why：为什么突然想自己做饭了？为什么不想点外卖了？
- Where：你做菜是从哪里学的呀？
- Who：你自己一个人做的吗，还是别人帮你做的？
- How：你是怎么学会做饭的？

**方法二 · 表态**
- 赞同："感觉自己做饭要比点外卖健康，以后我也试着自己做饭。"
- 反对："我觉得自己做饭太麻烦了，还是点外卖比较方便。"
- 其他："我也想自己做饭，但是我自己做的太难吃了。"

**方法三 · 相关记忆**（关键词：点外卖、做饭）
- "我曾经也想尝试自己做饭来着，我想做土豆烧排骨，结果把排骨都烧黑了。"
- "我特别害怕做饭，特别是炒菜，因为我小时候做饭的时候油溅到我身上烫伤了。"
- "现在点外卖越来越贵了，而且感觉卫生状况也不好，之前我点外卖竟然饭里面有一个虫子。"

**方法四 · 上深下切平移**（以"最近馋了，我好想吃火锅"为例）
- 上深：推断对方口味偏重口 → 推断对方是哪里人
- 下切：喜欢什么口味的火锅、一般下哪些菜、有想去的店吗、上次吃是什么时候、吃过哪些类型
- 平移：重庆的火锅好吃 → 想去重庆玩 → 你去过吗、感受怎么样

一句话产出十余个可接的方向——这就是"不会聊天"和"会聊天"的真实差距，不是口才，是有没有这套拆解动作。

## Key Takeaways
1. 不知道接什么，先用 5W1H 拆对方的陈述句。
2. 提问过量就切表态：赞同 / 反对 / 其他看法。
3. 抓关键词调取相关记忆，记忆要具体到有画面。
4. 话题快死时用上深（拔高）/ 下切（细化）/ 平移（拽回自己熟悉的领域）。
5. 平移是 i 人的主场工具：不懂的话题不必硬撑，横向挪走即可。
