# 第13课 small talk 聊什么

## Core Idea
small talk 的触发条件是"不忙的共处时刻"——电梯里遇到领导、午餐碰到同事、买咖啡遇到下属、下班等车看到搭档。多数人低头玩手机，但这几分钟是增进了解的最佳窗口。技术核心：**让对方有表达欲**。

## Frameworks Introduced

- **提问设计**：`抛出开放式问题 + 自己准备好答案`
  - ❌ "那家餐厅好吃吗？" → 对方一句"还行/一般"就结束
  - ✅ "周末你去吃的那家餐厅有什么推荐菜呀，我也试试" → 对方有得讲

- **四个即学即用的技巧**
  1. **关注对方的变化**：换发型、改变穿着风格、新耳环、新口红色号。Small talk 的核心是对交流对象抱有好奇心。例："今天的耳环很好看哎，这个口红的颜色刚好也很搭配，有链接么？"
  2. **围绕上一次交集展开**：讨论先前合作项目的后续和各自感受。注意——**非正式交流中多问感受，少问具体工作内容**。例："嗨 Lili，上次的项目后来进展得如何？一切顺利吗？你最近忙吗？"
  3. **围绕对方最近的动态**：对方在社交平台分享的美食、旅行、露营。例："昨天看到你去吃 X 店啦，那里什么比较好吃？我一直想去。"
  4. **通用版话题**（交集太少时用）：①公司附近新开的餐厅和咖啡店 ②最近公司活动举办情况 ③最近工作忙不忙 ④周末怎么过（适用于假期前一周和节假日刚结束那一周）⑤还有多少天年假、有什么安排

## Key Concepts
- **共处时刻**：双方都不忙、物理上在一起的短暂窗口
- **开放式问题**：不能用 yes/no 回答的问题，是表达欲的开关
- **感受 > 内容**：非正式场合问对方"感觉如何"，不问"具体做了什么"
- **好奇心**：small talk 的底层态度

## Mental Models
- **Use "这个问题能被一句话回答完吗"当设计提问时。** 能 → 换成开放式。
- **Use 对方的外观变化当最低成本的开场白。** 观察成本为零，效果是被重视感。
- **Use 通用话题当交集不足时。** 五个兜底话题保证永远有话可说。
- **Use 感受类提问当聊工作时。** 工作内容在非正式场合是负担，感受是连接。

## Anti-patterns
- **问 yes/no 问题**：一句话把天聊死。
- **涉及家庭、收入、公司内部传闻八卦**：明确列为敏感话题。
- **过度紧张防御、过分打听追问**：会让人不适。
- **聊太久、挖太深**：时间不宜过长，深度要适中。
- **低头玩手机**：把共处时刻浪费掉。

## Key Takeaways
1. small talk 的窗口是"不忙的共处时刻"，别低头玩手机。
2. 提问要开放式，并自己准备好答案。
3. 四技巧：关注变化、围绕上次交集、围绕最近动态、通用话题兜底。
4. 非正式场合问感受，不问工作内容细节。
5. 避开家庭、收入、内部八卦；时间别太长、深度别太深。
