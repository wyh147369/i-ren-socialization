# 第16课 手机社交礼仪

## Core Idea
微信沟通的好感度细则，分三段：**添加/拉群、日常沟通/汇报、换岗/解散群**。核心原则是**降低对方的理解成本 + 留下可追溯的记录**。

## Frameworks Introduced

- **添加与拉群**
  - 面对面加微信：**下位者主动询问**"是否方便加您微信"，并双手拿手机等待。若对方操作不熟练（如不会展示二维码），主动出示二维码请对方添加。
  - 添加时**务必备注简介**："X 总您好，我是 xx 公司 xx，请多关照"——方便对方快速了解你的工作身份。
  - 添加后**追加一条更详细的介绍**，点明业务范围："x 总幸会！我是 xx，主要负责 xx 公司 xx 业务。我的号码 xx，期待与您合作！"
  - 建工作群要**先发信息知会**，避免莫名其妙被拉群的尴尬：说明群用途 + 邀请 + 稍后事项会发至群内。

- **日常沟通与汇报**
  - 领导安排工作：回"收到，马上落实"。避免生硬的"嗯""哦"，也切勿回"。""111"
  - 请示咨询：**不要发"在吗？"**，礼貌直接说事——"x 总您好，目前项目推进中遇到一些问题，需要您支持定夺。具体情况①②③……"
  - **文字 > 语音**；一条信息把事说清；用【总-分-总】结构 + 序号、空格，让逻辑清晰
  - 需要语音时先简要说明；说不清就问"是否方便通个电话？大概需要占用您 x 分钟"——**千万不要连续 N 条 60 秒语音**
  - 重要电话结束后，编辑一条【沟通纪要】发过去：既明确重点、强调共识，也是**自我保护的留痕手段**
  - 如无特殊情况，休息时间尽量避免打扰

- **换岗与解散群**
  - 岗位变动或离职主动告知：说明接手人 + 感谢 + 祝福
  - 解散临时群要礼貌知会，**不要悄无声息地解散**

## Key Concepts
- **总-分-总结构**：微信长信息的组织方式
- **沟通纪要**：电话后的文字确认，兼有澄清与留痕两重作用
- **留痕**：产生分歧时的凭据，属于"留心眼"格（ch03）
- **在吗**：最典型的低效开场，把成本转嫁给对方

## Mental Models
- **Use "对方要读几秒才能懂"当写微信时。** 备注、简介、序号、总-分-总，都在降低这个数字。
- **Use 文字当默认载体。** 可搜索、可转发、可留痕，语音都不行。
- **Use 沟通纪要当重要电话的标配。** 一个动作同时买到明确性和凭据。
- **Use "直接说事"代替"在吗"。** 对方看到信息有意自会回复。

## Anti-patterns
- **发"在吗？"**：增加一轮往返，且对方无法预判工作量。
- **连续 N 条 60 秒语音**：明确点名"非常让人反感"。
- **回"。""111""嗯""哦"**：显得不重视、不严肃。
- **莫名其妙拉群不说明**：让人尴尬且不安。
- **悄无声息解散群**：不礼貌。
- **休息时间打扰**。

## Key Takeaways
1. 加微信：下位者主动询问，务必备注简介，加完再补详细介绍。
2. 建群先知会用途。
3. 领导安排工作回"收到，马上落实"。
4. 不发"在吗？"，直接说事。
5. 文字优先于语音，用总-分-总 + 序号；不连续发长语音。
6. 重要电话后发沟通纪要，既明确共识也留痕。
7. 换岗/离职主动告知；解散群要礼貌知会。
