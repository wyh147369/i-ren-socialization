# 第28课 教你如何吵架占上风

## Core Idea
明明有理却忍不住流泪、气势瞬间变弱、睡前反复后悔——这是"泪失禁"。成因是**害怕冲突**（多半源于成长于冲突激烈的原生家庭，形成了回避的条件反射），可以改。

**前提认知（很重要）**：吵架时对方无法理性思考，所以**不要抱有说服对方的期望**——本书的立场是"吵架就是为了气对方的，怎么气人怎么来，只攻击不说服"。

> 注意：本课的定位是**防守与破局**，不是日常沟通方式。它解决的是"你已经身处冲突且对方不讲理"的场景；正常分歧请用 ch12 的"对 + 确实 + 然后"。

## Frameworks Introduced

- **一｜对方持续攻击时：千万不要自证，把问题推回对方**
  - "我没有觉得有什么啊，你想要表达什么呢？请你把脑浆摇匀了再来和我说话"
  - "你要这么想我也没办法"
  - "也难怪你会这么想"（同时撇嘴、眼神由上到下扫视对方一遍、摇摇头）
  - "你说的这些我知道啊，那又怎么样，关你什么事"
  - "你嘴好臭"（伴随皱眉捂鼻子）
  - 原理：**自证就是把战场拉到对方设定的框架里**

- **二｜指出对方问题时：主语说"你"，不说"我"**
  - 铁律：**不要证明自己是对的，要证明对方是错的**
  - "你是个什么东西，就你也配" / "你自己听听你说的这些话可笑不可笑" / "你也太敏感了吧" / "你也太不成熟太自卑了吧，你别这样，大家会笑话你的"
  - 打法：**疯狂质疑对方，挖对方错的地方，反复质问，不正面回答对方的疑问**

- **三｜情绪控制：避免哭腔与泪失禁**
  - 关键点是**避免激动**。作者的自我训练：像看傻子一样看对方，情绪平和地输出，练就强心脏
  - 具体参数：**不用非常大声，语速可以慢一点，边说边面带微笑**，营造一种你在和对方唠嗑的感觉
  - 核心判断：**谁先急谁就输了**

- **四｜吵后不复盘于睡前**
  - 不要在睡前复盘，会越想越气
  - 改法：在笔记本上写"吵架攻略"——回忆曾吵过的架、理清思路、总结经验、提出整改措施；并告诉自己下次牢牢把握思路：**情绪稳定、不急不躁、质问反问疑问扣帽子**

## Key Concepts
- **泪失禁**：冲突中条件反射式流泪，气势瞬间崩塌
- **只攻击不说服**：本书对吵架目的的定义
- **主语说"你"**：把举证责任推给对方
- **谁先急谁就输**：情绪是吵架的计分板
- **吵架攻略**：把冲突经验书面化，替代睡前反刍

## Mental Models
- **Use "这不是辩论"当进入冲突时。** 放弃说服，才不会陷入自证陷阱。
- **Use 主语替换当进攻动作。** 说"我"是在辩护，说"你"是在指控。
- **Use 慢速 + 微笑当情绪稳压器。** 音量和语速是急迫度的信号，慢下来就等于没输。
- **Use 笔记本当反刍的替代品。** 睡前的情绪复盘要换成结构化的事后总结。

## Anti-patterns
- **自证**：对方攻击什么你就解释什么，战场就被对方定义了。
- **试图说服对方**：吵架中对方无法理性思考，这是无效投入。
- **激动、大声、快语速**：直接触发泪失禁，且先急者输。
- **睡前复盘**：越想越气，且影响睡眠。

## Key Takeaways
1. 吵架时不要指望说服对方——对方无法理性思考。
2. 被攻击时绝不自证，把问题推回对方。
3. 进攻时主语说"你"，证明对方是错的，不证明自己是对的。
4. 不正面回答对方疑问，反复质问对方。
5. 避免激动：语速慢一点、不用大声、面带微笑——谁先急谁就输。
6. 睡前不复盘，改为在笔记本上写吵架攻略。
