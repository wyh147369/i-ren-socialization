# 第4课 社恐变社牛的万能语料库

## Core Idea
所有聊天的关键只有一句：**对对方保持好奇并善于倾听**。在此之上，按对象不同套三套公式——不熟悉的同学、同学/同事闲聊、上级或老师。这一课是全书最可直接照抄的部分。

## Frameworks Introduced

- **公式 A｜路上碰到不太熟悉的人**：`打招呼 + 寒暄`
  - 外形变化（必须真诚，不要硬夸）："你今天戴的帽子好好看呀"、"你今天戴的耳环好适合你"、"你今天的口红色号好好看呀"
  - 对行为提问："你是去吃饭吗"、"你是去上课吗"、"你是回寝室吗"
  - 兜底话题：天气、最近忙不忙、好久没见
  - 收尾：对方回答完互相热情说再见。**目标只是留个好印象，不要恋战。**

- **公式 B｜同学/同事闲聊**：`双方交集 + 大众话题 + 互相安利 + 延伸话题`
  - 双方交集：吐槽学校/公司管理、吐槽食堂饭菜、课堂作业/工作内容、近期活动
  - 大众话题：热点八卦（"今天你看热搜了吗"）、星座 MBTI（"你的 MBTI 是什么"）、美食、天气
  - 互相安利：先夸后求——"你这件衣服好好看啊，在哪里买的"；也主动给——"我最近看到一个特好看的电影"、"哪家店很实惠"、"推荐一个很有趣的博主"
  - 延伸话题：聊一个话题后**不要立刻转移**，在原有话题上往深走。作者明说：延伸话题是"从不熟悉走向熟悉的基础"。

- **公式 C｜上级或老师**：`双方交集 + 寻求建议 + 生活话题`
  - 双方交集：一起做的工作项目、课题项目、公司/学校办的活动
  - 寻求建议：一箭双雕——既凸显对方地位，又真的答疑解惑。"老师，我最近在书中看到了 xxx 观点，我很不理解，想请教一下您的看法"、"最近在工作中遇到了一点困难，想向领导请教一下"
  - 生活话题：对年长者聊子女教育、养生保健、运动健康

## Key Concepts
- **语料库**：预置的、按人群分组的可说话清单，用来消除冷场
- **真诚前提**：夸外形"前提是一定要真诚！！不要硬夸，不然会很尴尬"
- **好奇 + 倾听**：所有聊天的底层态度，技术都在其次
- **安利**：既能索取推荐也能给予推荐，是双向的话题发生器
- **延伸话题**：不换话题而在原话题上加深，是关系升级的关键动作

## Mental Models
- **Think of 闲聊 as 不追求深度交流的场景。** 作者原话：与大多数人的交流都不会是深度交流——所以可以预置语料，不必临场发挥。
- **Use "夸外形 → 请求安利"作为万能链路。** 夸赞天然打开"哪里买的"这个口子，一句话生成三段对话。
- **Use 延伸话题当关系要升级时。** 频繁换话题 = 停留在浅层；在原话题深挖 = 走向熟悉。
- **Use 寻求建议当对方是上位者时。** 请教同时满足对方的被尊重需求和你的信息需求。

## Anti-patterns
- **硬夸**：不真诚的外形夸奖比不夸更尴尬，这是作者唯一加三个感叹号强调的禁忌。
- **聊完立刻换话题**：切断了从不熟到熟悉的路径。
- **对上级只聊工作**：年长者的生活话题（子女、养生、运动）才是拉近距离的入口。
- **指望临场发挥**：i 人的问题不是不会说话，是没有预置语料。

## Key Takeaways
1. 所有聊天的关键：对对方保持好奇并善于倾听。
2. 路上偶遇 = 打招呼 + 寒暄（外形变化 / 行为提问 / 天气忙不忙），留好印象就收。
3. 闲聊 = 交集 + 大众话题 + 互相安利 + 延伸话题。
4. 上级/老师 = 交集 + 寻求建议 + 生活话题（子女、养生、运动）。
5. 夸外形必须真诚，否则宁可不夸。
6. 不换话题而在原话题上延伸，是关系升级的动作。
