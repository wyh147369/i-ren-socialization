# 第14课 练习表达和接话的方法

## Core Idea
三条接话规则，本质是**事实与结论的互换补全**：对方给结论你补事实，对方给事实你补结论，对方两者都给你补一段类似经历。外加一条硬要求：**嘴巴必须刻意练，自言自语也要说出来。**

## Frameworks Introduced

- **规则一｜对方说了结论 → 你补充一个事实**
  - 结论 = 对方的观点、感受；事实 = 无可辩驳的东西
  - 例：对方"这里交通很便利。"（结论）→ 你"是啊，从这里步行到地铁站只需五分钟左右。"（事实）

- **规则二｜对方说了事实 → 你据此补充一个结论**
  - 例：对方"这一周都是暴雨天气。"（事实）→ 你"最近天气确实不好。"（结论）

- **规则三｜对方既说事实又说结论 → 你补充一段类似经历及细节**
  - 例：对方"这个综艺节目很搞笑，其中有一期是贾玲扮演的白娘子，她的表演让人捧腹大笑。" → 你"我也看过这个综艺节目。之前看过的一期，贾玲扮演的皇后，她说话时的语气和神态让我笑得肚子疼。"

- **练嘴巴**：长时间不说话，一到要说话的时候"就像茶壶里煮汤圆，有货倒不出"，支支吾吾。**刻意去练嘴巴，自言自语说也可以，一定要说出来。**（配合 ch06 的每天朗读 20 分钟）

## Key Concepts
- **事实 vs 结论**：本课的核心二分。事实可验证，结论是观点感受
- **互换补全**：接话的动作就是补对方没给的那一半
- **类似经历 + 细节**：当对方已经给全了，唯一的接法是横向给一段自己的经历
- **有货倒不出**：输入有了但输出肌肉没练，是 i 人的典型状态

## Mental Models
- **Use "他给的是事实还是结论"当你要接话时。** 缺哪一半就补哪一半，这是可机械执行的。
- **Use 细节当经历的燃料。** "我也看过"是死句，"贾玲演皇后时那语气让我笑到肚子疼"才是能接的话。
- **Use 自言自语当最低门槛的练习。** 练嘴巴不需要听众。

## Anti-patterns
- **只附和不补充**："是啊""对对对"不携带新信息，对话照样死。
- **补同类项**：对方给结论你也给结论，等于没接。
- **给抽象经历**：没有细节的"我也有过"无法引发对方的回应。
- **只输入不练嘴**：读了很多但不说出来，依然"有货倒不出"。

## Key Takeaways
1. 对方给结论 → 你补事实。
2. 对方给事实 → 你补结论。
3. 对方两者都给了 → 你补一段带细节的类似经历。
4. 嘴巴要刻意练，自言自语也算，必须说出来。
5. 练嘴巴和朗读（ch06）是同一件事的两面：输入够了还要练输出肌肉。
