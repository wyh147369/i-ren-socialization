# 第9课 套公式筛选朋友的秘诀

## Core Idea
**社交的本质是筛选。** 付出被视为理所当然、过度分享秒后悔、人际内耗——很大原因是没有做社交分类。开篇三句是本课全部立场的浓缩：不要高估他人对自己的善意；**爱人要爱成型的人，不要爱人身上的某种可能性，然后期待它成型**。

## Frameworks Introduced

- **社交关系六级分类**
  | 层级 | 判断标准 | 相处方式 | 功能 |
  |---|---|---|---|
  | ① 无所谓的关系 | — | 不投入 | — |
  | ② 浅层关系 | 状态好可以相处，状态不好不合适；仍在犹豫要不要继续 | 不谈隐私、建立边界感；被创可以创回去 / 远离 / 说清楚；只聊浅话题（穿搭、天气、美食）；可用夸奖赚好感塑造人设；**不花钱不花精力** | 分享欲、兴趣相投 |
  | ③ 深层关系 | 相互鼓励没有打压（真心意见不算打压）；负能量流通但不过度；能做真实自己、被"看见"；生理性舒适与放松；互相欣赏 | 让爱流通，表达爱与欣赏 | 人生支点 |
  | ④ 挚友 | 共同使命 | — | — |
  | ⑤ 利益关系 | 有擅长并变现的领域、能轻松解释专业名词、有好奇心、被夸奖不会飘、标准比较高 | 提高自己的价值（按需选取） | — |
  | ⑥ 对待他人方式 | 相处是否愉快（从生理表现发现问题）、是否双向（不是自我感动） | 肯定就尽量满足看到的需求；不是就心情好时随便聊聊，只聊双方感兴趣且无矛盾的话题 | — |

- **人际功能区分**：不同功能的朋友干不同的事。喜欢美食旅行的约着玩，喜欢学习进步的一起分享方法内容，喜欢天文的约一起观星。**不要强迫好友去做不感兴趣的事，只会都不尽兴。**

- **广结好友是断舍离的前提**：很多人屡屡被创仍维持联系，是因为"失去以后就没有朋友了"。所以要持续认识新朋友——但**自己的价值才是根本，技巧只是辅助**。

## Key Concepts
- **筛选**：社交的本质动作，不是经营
- **成型的人**：已经具备某品质的人，而非"有潜力成为"的人
- **可能性陷阱**：爱上一个人的潜力并期待它成型，是内耗的主要来源
- **生理性舒适**：身体层面的放松感，是判断深层关系的可信信号
- **自我感动**：单向付出却误判为双向
- **负能量流通但不过度**：深层关系允许抱怨，但有上限

## Mental Models
- **Use "这是浅层还是深层"当你在一段关系里纠结时。** 纠结本身往往就是错配的信号——用错了层级的相处方式。
- **Use 生理反应当判断依据。** 见面前是否放松、相处后是否疲惫，比理性分析更准。
- **Use "爱成型的人"当你在评估一个人值不值得投入时。** 不要为潜力买单。
- **Use 功能区分当关系让你失望时。** 让美食搭子承担人生支点的功能，双方都会失望。
- **Use 广结好友当断舍离的燃料。** 没有新朋友就不敢断，所以要持续扩展（见 ch08）。

## Anti-patterns
- **不分类**：所有关系用同一套投入方式，是内耗的根源。
- **高估他人对自己的善意**：本课开篇点名的误区。
- **为可能性买单**：期待对方的潜力成型。
- **自我感动式付出**：付出被视为理所当然，是因为对方从未要求。
- **强迫好友做不感兴趣的事**：功能错配，双方不尽兴。
- **只靠技巧不提升价值**："自己的价值才是根本，技巧只是辅助"。

## Worked Example
一个同事，午餐常一起吃、聊穿搭和美食很愉快，但你每次提到职业困惑对方就岔开话题，且你见面前会隐隐紧张。

按本课分类逐条过：
- **相互鼓励没有打压**？没到这一层，只是话题愉快 → 未达深层关系的"被看见"
- **生理性舒适与放松**？见面前会紧张 → 明确不满足深层关系判断项
- **浅层关系判断**：状态好可以相处，状态不好不合适 → **符合**

**结论：归入②浅层关系。** 对应动作全部改变——不再倾诉职业困惑（不谈隐私）、不再期待对方提供情绪支撑、只聊穿搭天气美食、不再为此人花额外的钱和精力。

这不是"这个人不值得交往"，而是**把这段关系放到正确的格子里**。错配解除后，内耗自然消失。

## Key Takeaways
1. 社交的本质是筛选，不是经营。
2. 不要高估他人对自己的善意。
3. 爱成型的人，不要爱人身上的可能性。
4. 按六级分类给每段关系归位：无所谓 / 浅层 / 深层 / 挚友 / 利益 / 其他。
5. 浅层关系：不谈隐私、有边界、只聊浅话题、不花钱不花精力。
6. 深层关系的硬指标：相互不打压、能真实做自己、生理性舒适。
7. 按功能分配朋友，别让一个人承担所有。
8. 持续认识新朋友，才敢做断舍离；但价值是根本，技巧只是辅助。
