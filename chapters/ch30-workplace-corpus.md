# 第30课 i人职场社交语料库

## Core Idea
作者的切身体会：i 人上班的痛苦，**除了搬砖，更多来自办公室社交压力**——插不进话、不知道怎么开口、一涉及打电话或开会发言就紧张焦虑。这一课是跟 e 人同事偷师 + 自我实践后总结的**七个场景话术集**，可直接照抄。

## Frameworks Introduced

- **场景一｜新入职**
  - **抓牢带你的人**：新手保护期提问不会显得唐突
  - 不知道干什么："谢谢 x 姐/x 哥带我，请问办公用品在哪里领？OA 怎么开通？" / "您什么时间方便的话，想请教下公司的工作时间安排，以及日常的办公流程～或者有什么制度文件可以发我学习一下吗？"
  - 被介绍给部门："大家好，我叫 xx，很高兴能加入部门，以后还请各位老师多多指教"
  - **第一天下班不要偷偷走**："x 姐/x 哥，今天谢谢您带我，看您也挺忙的，添麻烦啦！如果没什么别的事，我就先撤啦～明天见！"（和工位周围的人也说拜拜）

- **场景二｜会议发言**
  - 主汇报人："各位领导老师，下面我简要汇报一下 xxx 的情况。"——按 **前期背景 → 方案主体 → 重点问题 → 你的意见** 组织
  - 参会/反馈："刚刚 xx 老师提出的方案很有可行性，我非常赞同。我在这个基础上进行了一些思考，我们是否可以在[具体环节]增加[补充内容]，这样可以进一步优化方案。"；收尾用 **"可能想法很不够成熟，供大家参考探讨哈，谢谢"**
  - 表达观点："我有个想法，不知道是否可行…" / "我赞同[某人]的观点，另外我还想补充一点…" / "我有个疑问，关于[问题]，想请教一下大家…"
  - 回应他人："[某人]提到的[观点]很有启发性，我深受启发…" / "我理解[某人]的意思，我认为还可以从[角度]考虑…"
  - 总结："我来总结一下大家的意见…" / "今天的讨论很有收获，我学到了[内容]…" / "接下来我们可以[行动]，我会负责[任务]…"

- **场景三｜向领导汇报**
  - 汇报工作："领导，我来汇报一下[项目]的进展…" / "目前[项目]已经完成了[阶段]，接下来计划[行动]…" / "在[项目]中遇到了一些[问题]，我的解决方案是[方案]…"
  - 寻求指导："领导，关于[问题]，我想听听您的建议…" / "我目前的想法是[方案]，您觉得是否可行？"
  - 表达感谢："感谢领导的指导，我会继续努力的！" / "谢谢领导的支持，我会尽快完成[任务]！"

- **场景四｜电话沟通**（三段式）
  - "请问是 xx 老师吗？我是[部门]的[名字]。您好您好～我们目前在推进 xx 工作，涉及到 xx 问题与贵部相关，不知道是否是您负责？"
  - 若是 → 详述问题和需要的支持（确认业务 / 提供前期材料或资源 / 提供反馈意见）
  - 若不是 → "请问联系哪位老师比较合适？"

- **场景五｜偶遇闲聊**（三个启动动作）
  - **制造动静**：站起来伸懒腰 / 接杯水 / 发出点动静（"我靠，今天股市挺好啊"），有人和你眼神对接就可以开始
  - **拆零食**：看看谁不太忙，溜达过去——"这个超好吃，来点儿？"（作者评价：这招特别好使）
  - 话题：兴趣爱好（"我最近发现了一本超好看的书，真的绝了"）/ 热点（"你看新闻了吗？这也太 xxx 了吧"）/ 近期生活（"看你票圈去 xx 玩了，怎么样值得推荐不？"）/ 夸夸（"哇，你这个小摆件真好看，放在这儿整个桌面都变得更有格调了，求链接！"）

- **场景六｜请求帮助 / 提供帮助**
  - 请求："xx 老师，不好意思打扰你。我在处理 xxx，遇到了一个难题，就是[详细描述问题]。你在这方面经验丰富，能不能麻烦你抽点时间帮我看看？真的太感谢你了。"
  - 提供："xx 老师，我看你最近为了 xxx 天天加班，摸摸！我之前参与 xxx 的时候也有涉及 xxx，有一些前期材料，如果你需要的话，我可以发你哦，说不定能帮你省点时间。"

- **场景七｜讨论分工**
  - 主办分工："各位老师，那会后我会整理一个分工表和时间进度表，发给各位征求意见"
  - 不合理分工提建议："我对这次的分工安排有些想法。目前[具体分工]，我考虑到[不合理原因]，我认为或许可以调整为[合理建议]，这样既能充分发挥大家的优势，也能让项目推进更加顺畅。"

- **四条总原则**：真诚自然（不刻意模仿他人）/ 积极倾听（认真听并适当回应）/ 适度表达（不拘谨也不过度热情）/ 不断练习

## Key Concepts
- **新手保护期**：入职初期提问的合法性窗口，要抓牢带你的人
- **前期背景 → 方案主体 → 重点问题 → 你的意见**：汇报的四段结构
- **"可能想法很不够成熟，供大家参考探讨"**：i 人发表意见的安全收尾句
- **零食破冰**：最低成本的办公室闲聊启动器
- **分工表 + 时间进度表**：把口头分工落纸，减少后续麻烦

## Mental Models
- **Use 新手保护期当提问的合法窗口。** 过了这个窗口再问同样的问题就显得不专业。
- **Use "赞同 + 补充"当会议发言的万能结构。** 不否定任何人，同时表达你的内容。
- **Use 零食和动静当闲聊的物理触发器。** 等待别人来搭话是 i 人的被动陷阱。
- **Use 落纸当分工的收尾动作。** 口头分工 = 日后的争议源。

## Anti-patterns
- **第一天下班偷偷走**：放弃了一次低成本的好印象。
- **直接否定他人方案**：用"赞同 + 补充"替代。
- **等别人来找你聊**：办公室闲聊需要自己制造触发点。
- **分工只停留在口头**：事后必然扯皮。
- **刻意模仿 e 人**：作者明确要求"真诚自然，不要刻意模仿他人"。

## Worked Example
会上要反对同事的方案：

- ❌ "这个方案成本压不下来，我觉得不可行。"
- ✅ "刚刚 xx 老师提出的方案很有可行性，我非常赞同。我在这个基础上进行了一些思考，我们是否可以在[供应商选择]这个环节增加[备选供应商比对]，这样可以进一步优化方案，提升项目的完成质量。可能想法很不够成熟，供大家参考探讨哈，谢谢。"

四层结构：`赞同` → `在此基础上补充` → `收益说明` → `谦逊收尾`。反对意见完整到达，且没有人被否定。

## Key Takeaways
1. 新入职抓牢带你的人，第一天下班要打招呼再走。
2. 汇报按"前期背景 → 方案主体 → 重点问题 → 你的意见"。
3. 会议发言用"赞同 + 补充 + 收益 + 谦逊收尾"。
4. 电话三段式：确认身份 → 说明来意 → 判断对接人（是/不是都有话术）。
5. 偶遇闲聊靠制造动静或拆零食启动。
6. 讨论分工务必落到分工表 + 时间进度表。
7. 真诚自然、积极倾听、适度表达、不断练习。
