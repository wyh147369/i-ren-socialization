# 第21课 进入新环境如何避免边缘化/被孤立

## Core Idea
**被孤立的根本原因不是人品或关系，而是"社交封闭性"**——在这个有限的社交空间里，形成了隔绝你、膈应你的氛围。所以解法不是讨好，是**突破社交封闭性**。

## Frameworks Introduced

- **生活中三步**
  1. 初入环境**不与任何人交心**，但与大部分人维持表面关系；非必要不盲目抱团，**保持中立**
  2. 逐步拓宽社交圈：先和隔壁寝室交往（同样是表面关系），再通过室友的朋友、朋友的朋友慢慢扩大
  3. 挖掘合得来的人，形成稳定的社交圈——时间久了自然知道谁和你一类人，孤立就不会发生

- **职场中四步**
  1. 同样先不交心、先维持表面关系。**尤其不要和直属领导过度交往，风险过大**——相处好还好，相处不好以后别的同事也不敢搭理你
  2. 了解整个单位的规则和运行制度、不同部门的业务和人员分工（为了在仅有表面关系时工作不出大错）
  3. 扩大社交圈的同时，**寻找与同事领导超出工作外的关系**：老乡、同校、共同爱好、共同认识的人——这可以排除他人想要孤立你的恶意
  4. 积极向上社交：与直属领导合得来就多交往；不合得来就好好做事，并多与**他的上级**混个眼熟。上级喜欢你，直属领导就不敢轻易针对你；直属领导不针对，其他同事就不敢孤立你

- **已被孤立时的六条破局动作**
  1. **不要试图讨好孤立你的人**
  2. **不情绪外露**，当作什么都没发生，严格按规则办事
  3. 有意无意展现你与其他部门同事/其他同学的联系（叫他们来叫你一起用餐等）
  4. 比往常更努力做事，向上社交，**直接干到一把手那混个眼熟**——这时候谁也不敢轻易对你怎么样
  5. 利用线上社交（如晒网上的粉丝数），让别人觉得有很多人支持你，孤立你要冒被曝光的风险
  6. 有意无意展示攻击性（如桌上摆几本法律书、对着电话骂人），暗示你不好欺负

## Key Concepts
- **社交封闭性**：被孤立的真正成因——不是你做了什么，而是空间里的氛围已经形成
- **表面关系**：初期的安全距离状态，信息不深但连接存在
- **中立**：不盲目抱团，避免被绑进既有阵营
- **向上社交作为防护**：上级的注意本身就是对下级的保护
- **展示攻击性**：提高他人孤立你的预期成本

## Mental Models
- **Use "这是氛围问题不是人品问题"当被孤立时。** 归因错了就会去讨好，而讨好无效。
- **Use 表面关系当初期默认态。** 交心太快 = 押注错误阵营。
- **Use 工作外的联结点当破壁工具。** 老乡、同校、共同爱好能穿透职务壁垒。
- **Use "让孤立你变得有风险"当已被孤立时。** 展示外部支持、展示攻击性，都是在抬高对方成本。
- **Use 上级的注意当保护伞。** 这是一条现实而有效的职场生存逻辑。

## Anti-patterns
- **试图讨好孤立你的人**：明确列为第一条禁忌，无效且降低地位。
- **初入环境就交心/抱团**：押注风险极高，尤其别和直属领导过度交往。
- **情绪外露**：被孤立时情绪化等于给对方更多把柄。
- **只做工作不建连接**：只有职务关系时最容易形成封闭性。

## Key Takeaways
1. 被孤立的根因是社交封闭性，不是人品或关系。
2. 初期：不交心、广结表面关系、保持中立、不盲目抱团。
3. 逐步通过"朋友的朋友"扩大圈子，再沉淀稳定社交圈。
4. 职场：先摸清规则和分工，再找超出工作外的联结点（老乡/同校/爱好）。
5. 不与直属领导过度交往；积极向上社交，上级的眼熟是保护。
6. 已被孤立：不讨好、不露情绪、展现外部联系、更努力做事往上走、展示攻击性。
