# 第23课 高情商拒绝话术

## Core Idea
拒绝难，一半是思想问题一半是话术问题。思想上三个转变，话术上五套模板，按对方脸皮厚度递增。

## Frameworks Introduced

- **思想三转变**
  1. **不要太在乎他人对我们的看法**：i 人习惯性讨好、把别人的需求放在自己之上，根源是怕被讨厌。破法很硬——"他人的看法和评价根本一点也不重要，**谁影响你，你就放弃谁**，我们是为自己而活的。"
  2. **不要太过善良**："善良的人总能引来别人蹬鼻子上脸，性格软弱总会被别人不停占便宜。"适应社会第一步就是**让别人知道你脾气坏、你不好欺负**。
  3. **别人有权请求，我就有权拒绝**："既然别人都有脸来向你提出无理的请求了，那你当然有权利拒绝啦。"可以先考虑自己的想法和意愿——**你可以拒绝任何你不想接受的请求，且不需要任何理由**。

- **话术一｜说明理由 + 幽默化解**（同事/同学让你干分外之事）
  - "不好意思啊，我最近太忙咯，这次你就自己做哈，我虽然帮不了你，但我的心与你同在，加油！"
  - "你看我天天忙成这个样子咯，你竟然还想让我再干一些，你是不是想累④我"
  - 要点：**以开玩笑的语气说**，让双方氛围轻松

- **话术二｜明确态度 + 指明难处**（有人叫你参加聚会 / 找你帮忙）
  - "我也很想去和你们一起聚餐，但是我周末有约了，你们玩得开心"
  - "我也想给你看，但我这个笔记是别人借给我看的，他说不让外传"

- **话术三｜说明理由 + 提供其他方案**（关系不错的人请你帮忙）
  - "对不起啊宝，我还有事不能帮你跑一趟了，要不你叫个跑腿吧，很快滴"
  - "我也想帮你，可是我对这方面不太熟悉，害怕给你搞砸，你要不在网上找专业人士帮你搞这个？"

- **话术四｜延时回复 + 询问**（不熟的人网上请你帮忙 / 向你借钱）
  - 对方发消息后**过几个小时再回**："不好意思啊，刚才在忙，请问你还需要吗"；对方若还需要，再过几小时或更久回同样的话——**一般对方都会知难而退**
  - 精妙处：不拒绝，只是让对方的等待成本不断上升

- **话术五｜直接了当拒绝**（厚脸皮或不合理的请求）
  - "我不想，我拒绝，你自己干吧" / "我懒，不想动"
  - 前提判断：**面对无理的请求就不需要再给对方面子**——对方都不考虑你的感受了，你也不用给情面

## Key Concepts
- **蹬鼻子上脸**：过度善良的必然后果，本书用词很直白
- **不需要理由**：拒绝权的完整表述——这是本课最解放性的一句
- **延时回复**：用时间成本替代口头拒绝，适合不熟的人
- **献可替否**：话术三就是 ch12 里那条古语的现代版

## Mental Models
- **Use 对方的脸皮厚度当选择话术档位的依据。** 从幽默化解到直接拒绝，是一个梯度，不必一上来就最硬。
- **Use "我不需要理由"当心理许可。** 找理由只是为了让对方好下台，不是义务。
- **Use 延时当你不便正面拒绝时。** 不撕破脸，但让对方自己退。
- **Use "谁影响你，你就放弃谁"当关系取舍的底线。**

## Anti-patterns
- **因为怕对方难过而接受**：换来的是对方蹬鼻子上脸。
- **拒绝时反复道歉和解释**：解释越多越像心虚，也给了对方继续说服的空间。
- **对所有请求用同一档话术**：对厚脸皮的人用幽默化解，只会被当成好说话。
- **把别人的需求放在自己之上**：这是讨好型模式的根。

## Worked Example
不熟的同事在微信上找你借钱。

- 直接拒绝 → 撕破脸，日后还要共事
- 答应 → 大概率收不回，且被记为可借对象
- ✅ **话术四（延时回复 + 询问）**：
  - 第一次：隔几小时回"不好意思啊，刚才在忙，请问你还需要吗"
  - 若对方回"还需要"：再隔更久，回同一句
  - 通常对方会知难而退

为什么有效：**你一次都没有说"不"，但对方的等待成本在累积，且感受到你的冷淡。** 关系不破，事情也不成——这正是"不熟的人"这个场景下最优的解。

若对方厚脸皮继续纠缠，则升级到话术五，此时不必再给情面。

## Key Takeaways
1. 他人的看法不重要；谁影响你，你就放弃谁。
2. 过度善良会招来蹬鼻子上脸——让别人知道你不好欺负。
3. 别人有权请求，你就有权拒绝，且不需要理由。
4. 话术梯度：幽默化解 → 明确态度指明难处 → 说明理由给替代方案 → 延时回复 → 直接拒绝。
5. 不熟的人借钱/求助，用延时回复 + "请问你还需要吗"。
6. 面对无理请求不必给面子。
