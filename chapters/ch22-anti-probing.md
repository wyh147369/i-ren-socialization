# 第22课 防套话指南

## Core Idea
i 人面对套话只会如实回答，等于把把柄交出去。首选动作是**沉默**——"不回应就是最好的解决方式"。若沉默太尴尬，有四套话术。

## Frameworks Introduced

- **首选：沉默，不回应**
  - Why: 别有用心的人会先抛一个隐私问题测试反应。你秒答，对方就把你定义为"老实的傻子"，之后会持续打探。
  - 关键：**在对方第一次试探时就不要回应**，让他知道你不好惹。
  - 心理许可：**不要因为没回答而感到愧疚**——能问出让你不舒服的问题的人，本身就没有尊重你。

- **① 笼统回复 + 反问**（适用于问家庭、工资及其他隐私）
  - 问"你家里是做什么的" → "就普通打工人呀，你家里是做什么的呀" / "就做点小生意，你家里呢？"
  - 问"你工资多少" → "大家应该都差不多呀，你多少呀" / "就那样吧能养活自己，你呢？"
  - 问"有没有对象" → "怎么了，你要给我介绍对象嘛？"
  - 追着问 → "你干嘛，查户口啊？"
  - 原则：**不直接回答，通过反问把问题引回对方身上**

- **② 借口有事，打断谈话**（适用于任何场景，尤其对方刨根问底时）
  - "我突然想起来我还要 xxx，我先去了" / "等一下，我先去个卫生间" / "我现在活有点多，领导在催我了，之后再聊"

- **③ 开玩笑式夸张回复**
  - "你工资多少啊" → "也就不到一个亿，哈哈哈"
  - "你家里是做什么的" → "当大官的哈哈哈哈"

- **④ 反问法，主语换成对方，问为什么**
  - "啊？你为什么这么问呀" / "哦，你为啥突然这么问"
  - "你什么时候结婚？" → "你怎么突然问这个问题，你要结婚了嘛"
  - "你有对象了嘛？" → "你怎么突然关心这个了，你要给我介绍？"

- **收尾注意事项**：**对方没笑的情况下，你就不要尬笑**——尬笑会显得软弱。直视对方的眼睛，把回答的速度放慢。

## Key Concepts
- **试探性问题**：套话者的第一步，用来给你的"好欺负程度"打分
- **反问**：把问题引回对方，是防套话的通用动作
- **夸张回复**：用荒诞回答让对方无法继续追问
- **放慢语速 + 直视**：非语言的边界信号
- **尬笑**：软弱信号，必须戒除

## Mental Models
- **Use 沉默当第一选项。** 话术是退而求其次——不回应本身就在传递"你不好惹"。
- **Use 反问当默认应答。** 任何隐私问题都可以先问回去。
- **Use 夸张当终结技。** 荒诞答案让追问无法继续。
- **Use 语速和眼神当边界信号。** 内容之外，慢答 + 直视比说什么都重要。
- **Use "第一次试探"当关键节点。** 第一次就守住，后面就不会被持续打探。

## Anti-patterns
- **如实回答**：等于交出把柄，并被贴上"老实的傻子"标签。
- **因为没回答而愧疚**：不尊重你的人不配得到你的回答。
- **尬笑**：明确点名——会显得软弱。
- **回答太快**：配合直视与放慢语速才构成边界感。

## Worked Example
饭局上不太熟的人问："你现在一个月挣多少啊？"

- ❌ "也就一万出头吧……" → 信息交出，且被记为好打探的对象
- ✅ 反问法："你怎么突然问这个？"（对方多半会含糊过去）
- ✅ 若对方继续："大家应该都差不多呀，你多少呀？" —— 把球踢回去
- ✅ 若仍不放过：夸张法 "也就不到一个亿，哈哈哈" —— 用荒诞终结话题
- ✅ 配合动作：**不尬笑、直视对方、放慢语速**

四个层级可依次升级，不必一上来就用最硬的。

## Key Takeaways
1. 不回应是最好的解决方式——第一次试探就要守住。
2. 没回答不必愧疚，不尊重你的人不配得到答案。
3. 笼统回复 + 反问：把问题引回对方身上。
4. 借口有事打断：万能脱身法。
5. 夸张回复：用荒诞终结追问。
6. 反问"你为什么这么问"：揭示对方的动机。
7. 对方没笑就别尬笑；直视眼睛、放慢语速。
